See the CLM1PT_data subdirectory for the README explaining what goes there.

Place the subset domain and surface dataset files in this directory.  The files need to have the following format in which you replace <YOUR_SITE_NAME> to match the name of the site, which should match the name of the folder these files are in.

domain_<YOUR_SITE_NAME>_fates_tutorial.nc
surfdata_<YOUR_SITE_NAME>_fates_tutorial.nc

Note that this is setup to automatically work with the way the files are referenced in create_elm-fates-singlepoint-1pft_gswp3_invinit.sh.
